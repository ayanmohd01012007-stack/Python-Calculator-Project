# Python Calculator Project 🧮

A simple calculator project developed using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input
- Division by zero handling
- Invalid choice handling

## Technologies Used
- Python 3
- Visual Studio Code
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run this command:

```bash
python python-calculator.py
```
